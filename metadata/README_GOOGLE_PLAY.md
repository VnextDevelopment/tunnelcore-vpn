# TunnelCore VPN — Google Play Store listing

Titles stay `TunnelCore VPN`; images and screenshots are unchanged.

Descriptions have been prepared for 12 locales: en-US, ru-RU, tr-TR, ur, es-419, pt-BR, de-DE, fr-FR, ar, id, hi-IN, ka-GE.

To import translations: in Play Console's localized store listing screen, tap **Import translations with AI** > **Import file** and upload `metadata/google-play-import.csv`. The CSV contains locale, title, short_description, and full_description columns. Gemini's import recognizes structured files; review the mapping, recognized locales, and text before submission. This is **not a documented fixed CSV schema**, so parsing is not guaranteed.

Update default `en-US` title/short/full text manually first if needed. Importing translations does not itself publish the listing.

**Policy**: Android VpnService API disclosure and AmneziaWG encryption are included in every language. Wording claiming direct payment via Telegram bot was intentionally omitted to reduce the risk of violating Google Play Payments policy. No ads traffic manipulation claim is included.

All short descriptions <=80 chars; full descriptions <=4000 chars. Please arrange native-speaker proofreading where possible; store descriptions do not translate app UI.

The Android Play Release GitHub Action only builds AAB; merging does not update Google Play Console.
